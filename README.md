# Introduction

This project presents a data-driven analysis of the works of H. P. Lovecraft. The dataset is compiled from multiple sources, including bibliographies and publicly available GitHub repositories. Due to the manual nature of data collection, an initial preprocessing stage is required to clean, standardize, and structure the data for analysis.

The project is divided into two main components:

- **Textual Analysis**: Examination of linguistic features such as word count, sentence count, vocabulary usage, and other stylistic metrics.
- **Publication Analysis**: Exploration of metadata related to Lovecraft’s works, including the number of writings and publications per year, magazines where the stories were published, types of stories, collaborations, and the frequency of recurring entities within the narratives.

In addition, we perform statistical analyses on the textual data, investigating distributions and identifying patterns within individual works. This includes fitting probability distributions, computing correlations, and estimating relevant statistical measures.

Finally, we apply Fourier transform techniques to the texts, enabling further analysis of structural properties such as entropy.

The goal of this project is to combine literary analysis with quantitative methods, providing new insights into Lovecraft’s body of work.
